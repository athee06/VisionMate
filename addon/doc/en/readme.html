VisionMate

VisionMate describes images, screens and on-screen elements on your own computer, and makes windows that NVDA cannot read usable through an accessible overlay. Images are never sent to the internet, it works without a connection, and there are no accounts, keys or usage limits.

Getting started

After you install VisionMate and restart NVDA, a welcome window opens. VisionMate needs its vision data (about 1.5 GB), which is downloaded only once. Press Enter to start the download. While it downloads, press Space to hear the progress. When it finishes, the window shows a short usage guide. If the download is interrupted, it continues from where it stopped next time.

Commands

  • NVDA+Alt+A: describe the current element.
  • NVDA+Alt+W: describe the current window, without other windows or the taskbar.
  • NVDA+Alt+F: describe the whole screen.
  • NVDA+Alt+D: describe the image on the clipboard, or an image file you copied in File Explorer.
  • NVDA+Alt+O: open the overlay for the current window.
  • NVDA+Alt+G: turn automatic descriptions on or off.
  • NVDA+Alt+B: turn names for buttons without a name on or off.
  • NVDA+Alt+N: give your own name to the current button, or to the current item in the overlay.

Press a command once for a quick spoken description. Press it twice quickly for a longer, more detailed description, including visible text, shown in a window with Copy and Close buttons. Press Control to stop speaking.

For pictures of the screen, VisionMate also reads the text with Windows OCR, the same engine as NVDA+R, so names, numbers and codes are read exactly.

Questions about the image

The detailed description window has a question box. Type a question about the image, such as "What is the total?" or "What colour is her dress?", and press Enter. The answer is spoken and added to the window, so you can read it again. You can ask several questions in a row. Questions must be about the image: VisionMate does not answer anything else, such as greetings, small talk, general knowledge, maths, writing or jokes. For such questions you hear "I can only answer questions about this image."

The overlay for inaccessible windows

Some programs and games show buttons and menus that NVDA cannot read. Press NVDA+Alt+O in such a window. VisionMate reads the window's text with Windows OCR, finds its icons, and shows everything as a list, one item per line, top to bottom. The first line says the window's name and how many items there are. An icon with its name next to it, like a desktop shortcut, is one item.

VisionMate also works out how the window looks, from its shapes and colours:

  • Areas: when a window has several, like a dialog, a top bar, a left panel and the main area, each starts with a line like "Dialog: Sign in, 5 items". A dialog comes first, because it usually needs an answer. Columns side by side are read one after the other.
  • Kinds of item: buttons, edit fields, checkboxes and radio buttons (with checked or not checked), links and headings are said after their text, like "Save button" or "Remember me checkbox, checked". Text in a menu or list stays plain text. This works from the picture, so it can be wrong now and then.
  • Up and Down arrows, or Tab and Shift+Tab: move between items.
  • H, B, E, X, K and D: move to the next heading, button, edit field, checkbox or radio button, link, or area, as in browse mode. Add Shift to move to the previous one.
  • Enter: activate the item in the real window. Desktop shortcuts and files in a list are opened (a double click); everything else gets a single click.
  • Space: a single click, for example to only select a desktop shortcut.
  • Shift+Enter: always a double click.
  • Applications key or Shift+F10: right-click.
  • Escape, or NVDA+Alt+O again: close the overlay.

The overlay stays open until you close it. After a click it stays where it is and updates in place: only what changed is spoken. If the click opens another window, the overlay shows that window instead and says its name and number of items. If you switch to another program yourself, it closes.

  • Icons are named by the vision data, for example "Settings icon", or "Settings button" when the icon sits on its own button. The first time this takes a moment, and you hear "icon, naming" until the name is ready. Names are remembered for each program, so they are instant next time.
  • If a menu item looks selected, for example in a game menu you move with the arrow keys, the first line says which one, like "Selected: Continue".
  • The overlay keeps itself up to date as the window changes, about once a second, and new text is spoken. You can turn this off in settings.
  • If a name is wrong, press NVDA+Alt+N on the item and type a better one. Your names always win and are kept.

Limits: fast-moving gameplay cannot be followed. Some games in exclusive full screen give a black picture; use windowed or borderless mode. Some games ignore simulated clicks, and anti-cheat software may block them. Icon names are guesses and are sometimes wrong.

Names for buttons without a name

Many programs have buttons that NVDA can only call "button". When names for buttons are on (NVDA+Alt+B or in settings), VisionMate looks at the icon when such a button gets focus and says what it probably does, like "Probably Settings". Names are remembered for each program. Press NVDA+Alt+N to give a button your own name, which is then always used. It is off by default.

Automatic descriptions

When automatic descriptions are on, VisionMate describes images that have no useful label as you read web pages and documents in browse mode. A label is not useful when it is missing, only a file name or a link, or only a word like "image", "photo" or "placeholder". NVDA reads the line as usual, then you hear "Image:" and a one-sentence description. Each image is described once and remembered, so returning to it is instant. Decorative images are skipped: small icons, thin lines, blank images, and a picture that repeats in many places on the page, such as a bullet or a rating star. Moving on stops the description, so reading is never slowed down. While you read, images a little further down the page are described in the background, so they are ready when you reach them. Images that get focus in programs, and pictures in Word documents and Outlook emails, are described too. Turn it on or off with NVDA+Alt+G or in VisionMate settings. It is off by default.

You can change these commands in NVDA's Input Gestures dialog, under VisionMate.

Sounds

Each event has its own short sound:

  • Press a command once: one soft pluck. Press it twice: a lower double knock.
  • While waiting: a very quiet tick every second (can be turned off in settings).
  • Detailed description finished: two rising bell notes.
  • Question sent: a short rising whoosh. Answer arriving: a soft falling drop.
  • Overlay opens: three rising notes. Overlay closes: two falling notes. Item clicked: a tiny click.
  • Something went wrong: two low falling notes.

Settings

NVDA menu, Preferences, Settings, VisionMate:

  • Automatically describe images that have no label.
  • Describe images further down the page in the background: on by default.
  • Name buttons that have no name, from their icon: off by default.
  • Use Windows OCR to read screen text exactly: on by default.
  • Keep the overlay up to date as the window changes: on by default.
  • Use the graphics card: much faster. If the graphics card fails, VisionMate switches to the processor automatically.
  • Get ready when NVDA starts: the first description is as fast as the rest, but memory stays in use.
  • When the screen curtain is on, briefly lift it to take a picture: on by default. With the screen curtain on, the screen is black and VisionMate cannot see it. VisionMate turns the curtain off for a fraction of a second while it takes the picture, then turns it back on, without sounds and without changing your screen curtain settings. Anyone looking at your screen could see it flash for that moment. If the curtain cannot be turned back on, VisionMate warns you with a low two-note sound. Turn this off to keep the curtain on at all times; VisionMate then tells you it cannot see the screen.
  • Answer in NVDA's language.
  • Play a soft tick while waiting for a description.

Accuracy

VisionMate uses AI, and AI can make mistakes. Descriptions may miss or misread details, so please double-check anything important.

Speed and memory

On a laptop with an Intel Core Ultra 5 and its built-in graphics, a quick description starts in about 2 seconds (about 5 seconds without the graphics chip), and a detailed one (press twice) starts about 1 to 2 seconds after the first press. VisionMate uses about 3 GB of memory while it is ready. Your computer may be faster or slower.

VisionMate manages its memory by itself. If your computer runs low on memory, VisionMate gives its memory back after a minute unused, and gets ready again once enough memory is free. If "Get ready when NVDA starts" is off, VisionMate also gives its memory back after 10 minutes unused. After that, the next description takes a few seconds longer.

Updates

VisionMate updates come through the NVDA Add-on Store. When an update needs new vision data, VisionMate offers to download it after NVDA restarts.

Privacy

VisionMate does not collect any information about you or your use. It connects to the internet only to download its vision data.
